# 🌿 衣碳未来 - 移动端试用APP

## 📱 快速体验（手机直接打开）

### 方法一：在手机上直接打开
1. 将整个 `yitan_app` 文件夹上传到你的 **GitHub Pages** 或任意静态托管（如Vercel/Netlify）
2. 手机浏览器打开网址即可使用
3. 在 Safari/Chrome 中点击「分享」→「添加到主屏幕」，就像原生APP一样使用！

### 方法二：本地预览
用浏览器直接打开 `index.html` 即可

## 🛠️ 技术特性
- **PWA渐进式Web应用** - 支持添加到手机桌面
- **响应式设计** - 完美适配手机屏幕
- **离线缓存** - 通过Service Worker支持离线使用
- **一键安装** - 浏览器提示安装到桌面

## 📋 功能模块
| 模块 | 功能 |

| 🏠 首页 | 碳减排数据总览、快捷入口、环保动态 |

## 🖼️ 图标替换
将 `icons/icon.svg` 转换为PNG格式放入 `icons/` 目录：
- `icon-192.png` (192×192)
- `icon-512.png` (512×512)

在线转换工具：https://convertio.co/zh/svg-png/
